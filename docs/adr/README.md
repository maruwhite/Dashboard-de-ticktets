# Registro de decisiones de arquitectura (ADR)

Cada ADR documenta una decisión: contexto, decisión y consecuencias. Un ADR aceptado no se
edita para cambiar la decisión: se crea uno nuevo que lo reemplaza y se marca el anterior
como "Reemplazado por ADR-XXXX".
